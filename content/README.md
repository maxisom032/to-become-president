# События и дополнительные идеи

Это заготовка для будущего содержания, а не загружаемая игрой библиотека. События друга сюда не перенесены.

- unique-events/ — редкие или однократные крупные ситуации.
- side-events/ — необязательные личные, бытовые и комические ситуации.
- event-chains/ — связанные истории с отсроченными последствиями.
- ideas/ — дополнительные особенности и идеи, ещё не согласованные.
- templates/ — шаблоны описания.

Файлы называем по устойчивому идентификатору, например SE-001-short-name.md. Префиксы: UE — уникальное событие, SE — сайд-ивент, EC — цепочка, IDEA — идея. Номер после создания не меняем.

Статусы: идея → на обсуждении → согласовано → реализовано → проверено. Для исходных черновиков используем статус «идея». Не помечаем как реализованное то, чего ещё нет в коде. Риск и условия должны соответствовать целевой структуре в ../docs/TARGET_GAME_DESIGN.md.
