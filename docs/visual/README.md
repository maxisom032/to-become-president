# Визуал и взаимодействия

Актуально: [работающий прототип шести кабинетов](WORKPLACE_PROTOTYPE.md). Первый образец рисовки временно выбран, чистовой стиль ещё не утверждён.

Из прежнего предложения реализованы разные помещения и предметные взаимодействия. Все комнаты — 3D-геометрия. Папка, телефон, ежедневник и дверь реагируют на выбор. Персонажей в 3D ещё нет.

Названия партий теперь утверждены: Конституционный союз и Федеральный альянс. Старые варианты эмблем остаются только эскизами. Карьерное окружение описано в CAREER_PEOPLE_PARTIES_PROPOSAL.md; при расхождениях смотри последние согласования и PROJECT_CONTEXT.md.
