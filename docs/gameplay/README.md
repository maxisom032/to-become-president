# Геймплей и баланс

Основа: ../TARGET_GAME_DESIGN.md. Здесь будут уточнения по карьерной лестнице, обычному ходу, влиянию, деньгам, отношениям, инициативам, законопроектам, добровольному выдвижению и повторным выборам.

Около 100 ходов и 30–40 минут — ориентир для проверки, а не автоматический конец кампании. Повышение и понижение связаны с влиянием. Две партии имеют одинаковые механики. Окончательное поражение начинает полностью новую карьеру.

Правила старой 18-ходовой беты и её формулы не переносим. Новые параметры обозначаем как предложения до подтверждения пользователя. Тексты отдельных историй храним в ../../content/, художественные решения — в ../visual/.

Сначала прорабатываем полномочия рангов и цикл хода, затем показатели и последствия, затем избирательный этап. Согласованную структуру проверяем на коротком связанном фрагменте до расширения библиотеки событий.
