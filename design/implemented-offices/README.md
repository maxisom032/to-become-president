# Реальные кадры кабинетов

14 ноября 2026. Кадры Godot4.7.2, Vulkan Forward+ на Windows, RTX3060Ti. Это фактическая сцена движка: свет заранее запечён в Blender, геометрия остаётся объёмной. Сравнение с выбранными концептами — ../six-stage-offices/.

- comparison-clean.png — шесть чистых кадров рядом с подписями; comparison-clean-full.png — тот же ряд в полном разрешении.
- clean/ — отдельные кадры3D-сцены1080×1714 без интерфейса, сняты напрямую с SubViewport.
- comparison.png — шесть окон393×852 с интерфейсом, отдельные01…06 — те же окна.
- folder.png — приближение к открытой папке; highdpi.png — окно1080×2340; desktop.png —1920×1080.
- desktop-render-metrics.json — измерения только настольного рендера (98–105вызовов отрисовки всех областей, медиана интервала кадра около6мс); это не FPS на мобильном устройстве.

Команды: godot --path . --script res://tests/capture_presentation.gd и godot --path . --script res://tests/capture_art_quality.gd. Ряды составлены из настоящих кадров, только масштабирование и подписи, без ретуши.

18настольных Blender-моделей используют общую2048px текстуру с запечённым цветом и AO. Каждая статичная комната — одна2048px карта цвета и прямого/рассеянного света Cycles64samples. Дверь и папка продолжают двигаться отдельно; под предметами добавлены мягкие контактные тени. Готовые CC0-модели — Kenney и Poly Haven ArmChair_01/Sofa_01 (Kirill Sannikov), скачаны через Chrome, источники и лицензии в game/offices/assets/. Редактируемые .blend и производственные сценарии — tools/blender/.

Проверки:244 workplaces,433 presentation,116 career_interiors,0 ошибок polish; ещё51 проверка процедурного режима и возврата к bake. Растровая проверка восьми2048px карт прошла. Физические телефоны и iOS-сборка не проверены. Художественное качество оценивается по этим кадрам, точное совпадение с концептами не заявляется.
