# Шесть кабинетов рядом

14 ноября2026. Эскизы для выбора: не скриншоты готовой игры и не утверждённый финальный арт.

Порядок: Референт, Легат, Префект, Консул, Архонт, Первый архонт. Общий ряд — comparison-six-offices.png. Каждый кабинет сохранён отдельным вертикальным PNG.

Визуальная задача: одинаковый вид стола и предметов, одинаковая заметность двери чуть правее центра. Физическая высота и ширина двери может увеличиваться в большом помещении, сохраняя примерно прежнюю проекцию на экран. Развитие показывается обоями, отделкой, светильниками и мебелью. До Архонта окон нет, на двух последних ступенях — одно угловое окно слева. Оно относится к внешнему углу здания; дверь ведёт во внутренний коридор.

Метод: первый кадр задан по предыдущему предложению02-alcove; остальные пять созданы через редактирование первого кадра встроенным imagegen с сохранением переднего плана и расположения двери. Контактный ряд собран из готовых изображений без изменения их содержания. Источники и запросы/описания изменений — prompts.json.

Проверено визуально: шесть рангов читаются по заголовкам, стол имеет общую композицию, во всех сценах одна заметная дверь, окна только в двух поздних кабинетах. Точное совпадение координат при генерации не гарантируется; реализация в Godot должна закреплять проекции геометрически и проверять их на телефоне. Декоративные надписи и иконки не утверждают новые игровые действия.

При переносе в Godot: простая геометрия панелей и мебели, подготовленные текстуры отделки, тёплые источники света; камера и расположение предметов общие. Подробности оконных видов можно вынести в текстуры, сохранив объёмные рамы и согласованную перспективу двух сторон углового окна. Красивый эскиз сам по себе не подтверждает качество и скорость будущего рендера.
