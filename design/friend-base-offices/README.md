14 ноября 2026, Godot 4.7.2, OpenGL Compatibility, 414×780. Это кадры game/friend_offices/preview.tscn. comparison.png — Референт, Легат, Префект, Консул, Архонт, Первый архонт; folder.png и door.png — отдельные взаимодействия.
