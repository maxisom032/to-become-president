# Пробное оформление стола и наград

Статус: предложение для просмотра, ещё не перенесено в основную игру.

Реальные кадры Godot, 414×780. comparison.png: Префект, Консул, Архонт, Первый архонт. archons.png — последние две ступени рядом.

- Записная книжка убрана. Лотки с листами у Префекта и старших рангов сдвинуты к лампе, печать передвинута ближе к переднему краю стола; между предметами оставлен зазор.
- Префект: лоток с входящими документами перенесён ближе к лампе.
- Архонт: лоток с запечатанным письмом; две небольшие награды с росчерками подписи; графин со стаканом на боковой тумбе.
- Первый архонт: документ на подпись с ручкой; большая почётная грамота с двумя вымышленными декоративными подписями; графин и стакан на подносе.
- Прямоугольная верхняя табличка «Совет партии» у Консула/Архонта и правое панно у Первого архонта заменены лавровым медальоном. Чёрные подвесные светильники сохранены.

Для переснятия: godot --path . --script res://tests/capture_desk_awards_proposal.gd.
Примерка применяется только этим скриптом через game/friend_offices/proposals/desk_awards.gd, preview.tscn её не подключает. Ракурс камеры и папка сохранены. Это визуальные предметы, новых игровых действий они не добавляют.

Проверено: четыре реальных кадра, отсутствие ERROR/SCRIPT ERROR в журнале съёмки и визуальный осмотр обеих старших комнат. На физическом телефоне не проверялось.
