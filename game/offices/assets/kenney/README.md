# Готовая мебель Kenney

Источник: https://kenney.nl/assets/furniture-kit, автор Kenney, CC0. Архив скачан с официальной страницы 14 ноября2026; License.txt сохранён без изменений. Исходные glTF-модели не менялись. В игре материалы заменяются на общую палитру и текстуры кабинетов, размер приводится к месту установки.

Сейчас подключены chairCushion, plantSmall3 и pottedPlant. Другие модели сохранены для сравнения и последующего выбора; сам факт их наличия не означает использования. Телефон и открывающаяся папка пока остаются собственными моделями.
