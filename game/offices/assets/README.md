# Материалы кабинетов

14 ноября 2026. Внешние 3D-модели для этой доработки не скачивались.

## Созданные изображения

Четыре PNG созданы через imagegen для этого проекта и подключены к материалам настоящих 3D-моделей. Это не фоны вместо помещений. Точные исходные запросы здесь не восстановлены; ниже назначение материалов.

| Файл | Назначение | Исходный результат генерации |
| --- | --- | --- |
| textures/walnut.png | Тёплое ореховое дерево без нарисованного освещения | exec-7414a6fa-f60a-4c35-b731-ada8d9910b78.png |
| textures/plaster.png | Мелкая фактура окрашенной штукатурки | exec-1c0ec96f-da36-43fb-976e-e0c130fa02b3.png |
| textures/fabric.png | Ткань для перегородок, обивки и настольного покрытия | exec-b8b37481-67bc-4e07-a015-80558c6389e7.png |
| textures/district_map.png | Стилизованная вымышленная карта района | exec-a9234774-8a6f-487b-9ef6-b9df2cec794b.png |

Импорт ограничен 1024 пикселями, включены mipmaps. Шейдер окрашивает материалы в палитру комнаты. Бесшовность при любом масштабе отдельно не гарантируется; нормали и отдельные PBR-карты не созданы.

## Геометрия и шрифты

- Мебель с фасками, папка, телефон, растения и виды за окном создаются собственным кодом в game/offices/.
- PT Serif Regular и Bold — ParaType, SIL Open Font License 1.1. Лицензия сохранена рядом со шрифтами: ../../art/fonts/OFL-PTSerif.txt.
- Визуальные приёмы исходного кабинета друга отражены в ../../../docs/reviews/FRIEND_REPOSITORY_REVIEW.md. Его герои и игровые события не переносились.

Если позднее добавляются бесплатные внешние модели, для каждой нужно сохранить точную страницу источника, автора, лицензию и изменения модели. Пометка «бесплатно» сама по себе не заменяет условия лицензии.
