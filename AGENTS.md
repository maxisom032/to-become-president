# Работа над To Become President

Отвечай по-русски, на ты. Перед изменениями прочитай README.md, docs/PROJECT_CONTEXT.md и docs/TARGET_GAME_DESIGN.md.

## Основа разработки

Из проекта друга разрешено использовать ТОЛЬКО оформление 3D-кабинета и код, необходимый для его геометрии, материалов, света и отображения. Старый геймплей, правила, персонажи и события не переносить. Более раннее требование полностью исключить даже кабинет отменено последним уточнением пользователя.

Геймплей берём из обсуждения пользователя в docs/TARGET_GAME_DESIGN.md. Референт → Легат → Префект → Консул → Архонт → Первый архонт — согласованные названия. Четыре оформления просмотрщика не ограничивают эту лестницу.

Иллюстрации в design/character-refinements/ — сравнение стиля, не утверждённые игровые персонажи. Не считай картинки готовыми 3D-моделями. Сохраняй 3D-формат комнаты.

## Файлы и совместная работа

- game/office_room.gd — только оформление комнаты, game/office_preview.tscn — просмотрщик.
- docs/visual/ и design/ — визуальная проработка.
- docs/gameplay/ — правила и баланс, content/ — будущее содержание.

Несколько чатов работают в общей папке. Проверяй актуальные файлы, не перезаписывай чужую работу. Ключи и секреты храни вне проекта. Новый игровой процесс пока не реализован.

## Проверка

Godot 4.7.2: `godot --headless --editor --import --path .`, затем `godot --headless --path . --quit-after 30`. Проверяй вывод на SCRIPT ERROR и ERROR, одного exit code недостаточно. Визуальные изменения проверяй в вертикальном окне. Документы должны отличать уже работающее поведение от предложений.
